# Glossary

Words that mean something specific in this brain, and words that mislead. `CLAUDE.md` loads this file
into every session, so keep it short: one line per term, in alphabetical order.

Format: **term**: what it means here. Avoid: the words not to use for it. Not: what it is easily
taken for.

<!-- Example: **node**: one physical machine in the cluster. Avoid: host, server. Not: a Node.js process. -->
