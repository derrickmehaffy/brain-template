# Docs

An index of what lives under `docs/`. Add a line here when a new folder lands.

- `practices/`: one file per fact this brain has already worked out, searchable with
  `_meta/brain practices search <terms>`

The standing files:

- `ROUTING.md`: the routing map of this brain's own skills
- `GLOSSARY.md`: terms that mean something specific here, loaded into every session
- `CAPABILITIES.md`: what each system can and cannot do, dated
- `RETRO-LOG.md`: failures on real work, and the change that fixed each
- `UNCLASSIFIED-LOG.md`: work no skill fit, which is where new skills come from
- `UPSTREAM.md`: changes proposed to template-owned files, and their answers
- `INBOX.md`: work another brain handed over to this one, and whether it is done
